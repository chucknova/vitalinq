hospital.py — The search system. NearbySearchRequest defines what the API expects when someone searches (lat, lng, radius, optional bed type filter). HospitalSearchResult defines what comes back (hospital name, distance, beds by type, equipment, trust tier, composite score). Also covers triage requests (natural language → Claude → enriched search) and the web dashboard bed update endpoint.
handshake.py — The bed reservation lifecycle. Creating a handshake, checking its status (with countdown timer), and marking it complete when the patient arrives. The transfer_code field is the 6-character code both parties use as confirmation.
query.py — Query logging (for Ghost Bed Detection follow-ups) and the Dispatch Command overview, which bundles hospitals + active handshakes + surge predictions into one response so the dispatcher dashboard loads in a single API call.
